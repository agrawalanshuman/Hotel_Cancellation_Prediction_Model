# Private competition inputs
Place authorized train.csv, test.csv, sample_submission.csv in data/raw/ or set DATA_DIR to a private directory. The uploaded files were copied locally and ignored by Git. Do not obtain the original public hotel dataset or add external data.

Join the invitation through your own Kaggle account, accept rules, then download the three competition files from its Data tab. No credentials are required for the manually uploaded files. If using Kaggle tools, use Colab Secrets or a supported runtime login; never paste tokens into notebooks or commit kaggle.json. Exact schema and ID checks run in src.data_loader. File hashes are recorded with every experiment.
