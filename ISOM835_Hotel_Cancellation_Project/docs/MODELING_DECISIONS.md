# Modeling decisions
Prediction moment: provisionally booking creation; instructor confirmation pending. Known outcome fields are rejected by input validation and dropped defensively. ID is never a predictor. Seed 835 matches the accessible starter (instead of illustrative seed 42 in the request).

Professor baseline keeps numeric agent/company, median + standard scaling, constant missing strings + OHE min_frequency=20, logistic max_iter=3000. Our wrapper also excludes IDs/known leaks, as the source does. keep_empty_features=True only affects all-missing folds; verify equivalence on actual columns. Corrected encoding treats IDs as labels. Conservative defaults drop the seven explicitly questioned fields; remaining features are candidates, not certified safe. ADR, required parking, prior history and reserved room may also be revised; review timestamps. Use --drop for controlled additional exclusions.

HistGradientBoosting uses ordinal encoding (unknown -1) to avoid dense one-hot explosion; categories are ordered by the encoder, so this is a practical candidate, not a faithful native categorical treatment. Regularization, limited leaves and internal early stopping are configured. Its internal validation is inside each training fold, never the outer fold. Tree/forest parameters limit overfit. LightGBM/XGBoost are not installed or run until course permission is verified. Ensemble is optional and unrun; if used, learn weights only on OOF predictions with an explicit nested tuning plan.

Derived features use row-local arithmetic, no target statistics: nights, guests, weekend share, prior cancellation, repeat guest and log lead time. Timing inherits source fields and still needs review. Calibration is evaluated on OOF predictions, not training predictions. No external data or test outcomes are used. Public Kaggle is never the selection objective. Five-fold model comparison can be optimistic after tuning; secondary time/group validation is diagnostic and must disclose coverage.
